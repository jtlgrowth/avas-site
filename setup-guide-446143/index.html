STEP 02Install Claude Code

This is the part that looks scary and takes 90 seconds. You're going to paste one line into a program called the Terminal. You don't need to understand it — you're installing an app, just without a download button.

On a Mac

Press Cmd + Space, type Terminal, hit Enter. A small window with text opens. Paste this in and press Enter:

curl -fsSL https://claude.ai/install.sh | bash

Wait for it to finish, then close the Terminal window completely and open a new one. This step matters — the new window is what picks up the install.

On Windows — click to expand

Press the Start button, type PowerShell, and open it. Paste this in and press Enter:

irm https://claude.ai/install.ps1 | iex

Then close PowerShell and open a fresh window.

Two things worth knowing on Windows:

  • You need Windows 10 (version 1809 or newer) or Windows 11.
  • We recommend also installing Git for Windows. Accept every default in its installer. It's optional, but it makes Claude Code work the same way it does on the Macs we'll be demoing from.

If you see 'irm' is not recognized, you opened Command Prompt instead of PowerShell. Close it and search for PowerShell specifically.

If the install command fails — click to expand

Don't fight it. Message us and we'll sort it out before the day, or catch you at the Setup Clinic over lunch on Day 1.

Two things that fix most cases:

  • Check your macOS version. Claude Code needs macOS 13 or newer. Apple menu → About This Mac.
  • Try a different network. Some office and hotel wifi blocks the install. Phone hotspot usually works.
Now prove it worked.

In your fresh Terminal or PowerShell window, type this and press Enter:

claude --version

If you see a version number — something like 2.1.220 (Claude Code) — you're done. Screenshot that line and keep it. We'll ask for it.

If you instead see command not found, you're probably still in the old window. Close it, open a new one, and try again.

STEP 03Create a free Netlify account

Go to netlify.com and sign up. This is where the tool you build on Day 1 goes live on the internet with a real link you can send people.

Genuinely free. No card, no trial clock. Signing up with your Google account is the fastest route.

Don't skip this one thinking you'll do it on the day. On Day 1 you'll publish your tool in about fifteen seconds — but until you log in and claim it, the link is password-protected and expires within the hour. The account is what makes your tool permanently yours. Two minutes now saves you the one step that would otherwise leave you with a dead link.

Write your login down somewhere you'll find it on August 22. "I made the account but I can't remember the password" is the most common way this goes wrong.
